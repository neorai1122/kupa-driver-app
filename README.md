# קופת הנהג — ניהול כסף לדריבר

אפליקציית ווב (PWA) בעברית, מותאמת למובייל, לניהול כסף של נהגי דריבר בישראל.
סגנון נקי, מקצועי, דק ואלגנטי — ללא צבעים ילדותיים. RTL.

## מודל עסקי

- **הכנסה** — נסיעות (ברוטו שהנהג קיבל).
- **סדרן** — מי שמסדר נסיעות, מקבל **אחוז קבוע מכל נסיעה** (ברירת מחדל 30%).
- **רכב** — אחד מ-4 מצבים (נבחר באשף הגדרה): שכירות / מימון-הלוואה (+ביטוח בנפרד) / ליסינג (תשלום אחד שכולל הכל חוץ מדלק) / בבעלות (בלי תשלום חודשי, +ביטוח בנפרד). ברירת מחדל: לא מוגדר (0), עד שהנהג ממלא את האשף.
- **ביטוח** — עלות חודשית נפרדת (חובה/צד ג׳/מקיף), מתווספת לעלות הרכב היומית — רלוונטי לכל הסוגים חוץ מליסינג (שם זה כלול בתשלום).
- **הוצאות** — דלק, קניות, כלים וכו'.

רווח נטו = הכנסות ברוטו − עמלת סדרן − הוצאות − עלות רכב יומית (רכב+ביטוח ÷ ימי עבודה).

## אחסון וסנכרון

- **לוקלי:** `localStorage` (מפתח `kupaNehed.v2`) — תמיד השכבה הראשונה, האפליקציה עובדת גם אופליין.
- **ענן — קוד אישי:** בכניסה הראשונה חייבים לבחור "קוד אישי" (מסך חוסם, לא ניתן לדלג). הקוד מקשר את כל הנתונים ל-Firebase Firestore (collection `kupaDriverAccounts`), כך שאפשר לשחזר אותם בכל מכשיר נוסף פשוט בהקלדת אותו קוד. סנכרון אוטומטי דו-כיווני בזמן אמת ברקע — בלי צורך לשמור/לייצא ידנית.
- גיבוי/שחזור ידני דרך JSON נשאר זמין כגיבוי נוסף (כפתורים בהגדרות: "גיבוי" / "שחזור מקובץ גיבוי").

## מבנה ה-State

```js
state = {
  settings: {
    name, pct:30, dark, goal, fundPct:10, ownerPhone, remindOn, remindTime,
    lastMethod, rent:0, workDays:24, autoRent:true,
    ownershipType,     // '' | 'rent' | 'finance' | 'leasing' | 'owned' — נקבע באשף
    insuranceType,     // '' | 'חובה' | 'צד ג׳' | 'מקיף' | 'included' (בליסינג)
    insuranceMonthly:0, autoIns:true,
    wizardDone:false,  // האם אשף ההגדרה כבר רץ פעם
    syncCode:'',        // הקוד האישי — מפתח לסנכרון בענן (Firestore)
    lastRidePct:null    // אחוז העמלה האחרון שנבחר, מוצע כברירת מחדל בפעם הבאה
  },
  tx: [],        // עסקאות {id,type,cat,amount,date,note,ts,method,pct}
                 // pct רלוונטי רק לתנועות rides — אחוז עמלה ספציפי לנסיעה הזו (דורס את settings.pct)
  shifts: [],    // משמרות
  fund: {balance, log:[]},
  meta: {best, goalToast, notified, coveredDay, dismiss},
  updatedAt
}
```

### קטגוריות עסקאות

- הכנסה: `rides` (נסיעות), `income` (הכנסות אחרות).
- הוצאה: `commission` (לסדרן), `rent` (שכירות/מימון רכב), `insurance` (ביטוח), `fuel` (דלק), `expense` (הוצאות אחרות).

### לוגיקת סכומים

- `sums(list)` מחזיר `{inc, com, exp, rides, due}` — `due` מחושב per-transaction לפי `ridePct(t)` של כל נסיעה (לא אחוז גלובלי אחיד).
- עמלת סדרן: `ridePct(t) = t.pct ?? settings.pct`, מסוכם על כל הנסיעות ל-`due`.
- נטו: `inc − due − exp`.
- `carDailyCost()`: `(rent + insuranceMonthly) / workDays`.

## אשף הגדרת פרופיל רכב

- רץ אוטומטית בפעם הראשונה שהאפליקציה נפתחת (`!settings.wizardDone`), וגם זמין תמיד דרך כפתור "עדכון פרופיל" בהגדרות (`data-act="run-wizard"` → `openWizard()`).
- שלבים: סוג בעלות (שכירות/מימון/בבעלות) → סכום חודשי (אם רלוונטי) → סוג ביטוח → עלות ביטוח חודשית → מסך סיכום עם העלות היומית המחושבת.
- קוד: `openWizard()` + `wizStep1..4()` + `wizFinish()`, בסמוך ללוגיקת ה-sheet בקובץ `index.html`.

## הגדרות עיקריות (באפליקציה)

- סוג בעלות רכב, תשלום חודשי (שכירות/מימון), ביטוח וסוגו, ימי עבודה, תשלום רכב/ביטוח אוטומטי בהוצאות.
- עמלת סדרן (%), טלפון סדרן.
- עמלת סדרן אוטומטית מתווספת בכל רישום נסיעה (תחת "לסדרן").
