התקנה וענן — שלב אחר שלב

5 דקות עבודה חד־פעמית, והאפליקציה שלך חיה לתמיד: כתובת קבועה, אייקון במסך הבית, וגיבוי ענן אוטומטי. הכול בחינם.

1יצירת חשבון GitHub (חינם)

  1. כנס ל־github.com/signup
  2. מלא אימייל + סיסמה + שם משתמש (באנגלית, בלי רווחים) — לחץ Sign up ואשר את המייל

2העלאת האפליקציה לאינטרנט

  1. בתוך GitHub: לחץ + למעלה ← New repository
  2. שם: kupa · Public · לחץ Create repository
  3. לחץ על הקישור uploading an existing file
  4. העלה את כל הקבצים מהתיקייה: index.html, manifest.json, sw.js, guide.html וארבעת האייקונים icon-*.png — ואז Commit changes
  5. נכנס ל־Settings ← בתפריט הצד Pages ← תחת Branch בחר main ← Save
  6. אחרי דקה־שתיים האתר חי בכתובת: https://השם-שלך.github.io/kupa/
💡 הכתובת הזו היא שלך לתמיד. שמור אותה במועדפים.

3התקנה במסך הבית (כמו אפליקציה רגילה)

  1. פתח את הכתובת החדשה בדפדפן הטלפון
  2. אנדרואיד (Chrome): תפריט ⋮ ← ״התקן אפליקציה״ או ״הוספה למסך הבית״
  3. אייפון (Safari): כפתור שיתוף ← ״הוסף למסך הבית״
✅ מעכשיו יש לך אייקון צהוב במסך הבית — נפתח במסך מלא, עובד גם בלי אינטרנט.

4הפעלת ענן — גיבוי וסנכרון אוטומטי

  1. בתוך GitHub: פתח github.com/settings/tokens
  2. לחץ Generate new token ← בחר Generate new token (classic)
  3. שם: kupa · תוקף: No expiration · סמן V רק ליד gist
  4. גלול למטה ← Generate token ← העתק את המפתח (מתחיל ב־ghp_)
  5. באפליקציה: הגדרות ← סנכרון ענן ← הדבק את המפתח ← חיבור והפעלת הענן
  6. תקבל קוד סנכרון — העתק ושלח לעצמך בוואטסאפ (הוא המפתח לשחזור במכשירים נוספים)
🔐 הנתונים נשמרים ב־Gist פרטי בחשבון GitHub שלך בלבד. המפתח נשמר רק במכשיר. אל תשתף אותם עם אף אחד.

5מכשיר נוסף / טלפון חדש

  1. פתח את כתובת האפליקציה במכשיר החדש
  2. הגדרות ← סנכרון ענן ← הדבק את ה־מפתח ואת קוד הסנכרון ← לחץ חיבור
  3. הנתונים יורדים לבד, ומכאן הכול מסתנכרן לשני הכיוונים

?שאלות נפוצות

  1. החלפתי טלפון ואיבדתי הכול — למה? בלי ענן הנתונים נשמרים רק במכשיר. תמיד כדאי להפעיל את הענן (שלב 4).
  2. זה עולה כסף? לא. GitHub Pages ו־Gist חינמיים לגמרי.
  3. מי רואה את הנתונים? רק אתה. ה־Gist פרטי (Secret), והאתר עצמו לא שומר דבר בשרת.
  4. רוצה לעדכן גרסה? מעלים את הקבצים החדשים לריפו (Add file → Upload) והאתר מתעדכן תוך דקה.
