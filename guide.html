התקנה וענן — שלב אחר שלב

5 דקות עבודה חד־פעמית, והאפליקציה שלך חיה לתמיד: כתובת קבועה, אייקון במסך הבית, וגיבוי ענן אוטומטי. הכול בחינם.

1יצירת חשבון GitHub (חינם)

  1. כנס ל־github.com/signup
  2. מלא אימייל + סיסמה + שם משתמש (באנגלית, בלי רווחים) — לחץ Sign up ואשר את המייל

2העלאת האפליקציה לאינטרנט

  1. בתוך GitHub: לחץ + למעלה ← New repository
  2. שם: kupa · Public · לחץ Create repository
  3. לחץ על הקישור uploading an existing file
  4. העלה את כל הקבצים מהתיקייה: index.html, manifest.json, sw.js, guide.html וארבעת האייקונים icon-*.png — ואז Commit changes
  5. נכנס ל־Settings ← בתפריט הצד Pages ← תחת Branch בחר main ← Save
  6. אחרי דקה־שתיים האתר חי בכתובת: https://השם-שלך.github.io/kupa/
💡 הכתובת הזו היא שלך לתמיד. שמור אותה במועדפים.

3התקנה במסך הבית (כמו אפליקציה רגילה)

  1. פתח את הכתובת החדשה בדפדפן הטלפון
  2. אנדרואיד (Chrome): תפריט ⋮ ← ״התקן אפליקציה״ או ״הוספה למסך הבית״
  3. אייפון (Safari): כפתור שיתוף ← ״הוסף למסך הבית״
✅ מעכשיו יש לך אייקון צהוב במסך הבית — נפתח במסך מלא, עובד גם בלי אינטרנט.

4הקוד האישי שלך — שהנתונים לעולם לא יאבדו

  1. בפתיחה הראשונה של האפליקציה מתבקשים לבחור קוד אישי (למשל השם שלך + מספר). זה שלב חובה — לא ניתן לדלג עליו.
  2. הקוד הזה מקשר את כל הנתונים שלך לגיבוי אוטומטי בענן, שמתעדכן לבד ברקע בכל פעם שמוסיפים תנועה.
  3. מכשיר חדש / טלפון נוסף? פותחים את האפליקציה, בוחרים "יש לי כבר קוד", מקלידים בדיוק את אותו קוד — וכל הנתונים חוזרים אוטומטית.
  4. שני מכשירים עם אותו קוד מסתנכרנים אוטומטית וברציפות — הוספת תנועה באחד מופיעה מיד בשני.
✅ כל מי שנכנס לקישור בוחר קוד משלו — אין שיתוף נתונים בין אנשים שונים, אלא אם בחרו לבד באותו קוד.

?שאלות נפוצות

  1. החלפתי טלפון ואיבדתי הכול — למה? לא אמור לקרות יותר — פשוט הקלידו במכשיר החדש "יש לי כבר קוד" עם הקוד שלכם.
  2. שכחתי את הקוד שלי — מה עושים? אפשר לראות ולהעתיק אותו בכל רגע: הגדרות ← "הנתונים שלי" ← "קוד אישי". חשוב לשמור אותו במקום בטוח (כמו וואטסאפ לעצמכם).
  3. מישהו בחר בטעות את הקוד שכבר בחרתי? המערכת חוסמת את זה — אם הקוד תפוס, מבקשים לבחור קוד אחר.
  4. זה עולה כסף? לא. הכול חינמי לגמרי.
  5. מי רואה את הנתונים? רק מי שיודע את הקוד המדויק שלך.
  6. רוצה לעדכן גרסה? מעלים את הקבצים החדשים לריפו (Add file → Upload) והאתר מתעדכן תוך דקה, ומי שכבר מותקן מקבל את זה אוטומטית — בלי לאבד נתונים.
